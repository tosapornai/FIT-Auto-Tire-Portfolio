# FIT Auto Tire Portfolio Dashboard

Dashboard ติดตามยอดซื้อ ยอดขาย เป้า และสต็อกยางของ FIT Auto (เฉพาะสาขา COCO 110 สาขา)

## ไฟล์ในโฟลเดอร์นี้
- `index.html`: ตัว Dashboard (มีข้อมูลฝังในไฟล์แล้ว เปิดได้ทันที)
- `data.json`: ข้อมูลยอดขาย ยอดซื้อ และเป้า
- `stock.json`: ข้อมูลสต็อกรายสาขา
- `loc.json`: ข้อมูลที่ตั้งสาขา (ใช้คำนวณการโอนย้าย)
- `hist.json`: ยอดขายย้อนหลัง 2022–2024 รายเดือน (ใช้ในหน้า 07 ขอบยาง/ขนาดยาง ไม่ต้องอัปเดตรายเดือน)
- `vercel.json`, `robots.txt`: ตั้งค่าไม่ให้ search engine เก็บหน้าเว็บ

## อัปเดตข้อมูลรายเดือน
1. เปิด Dashboard แล้วกด "อัปเดตข้อมูล" เลือกไฟล์ Excel ยอดขายและสต็อก
2. ตรวจข้อความเตือนในหน้าตรวจก่อนบันทึก แล้วกด "ดาวน์โหลดไฟล์ข้อมูล (.json)"
3. นำไฟล์ `data.json` / `stock.json` ที่ได้ไปวางทับในโฟลเดอร์นี้ แล้ว commit ขึ้น GitHub (Vercel จะ deploy ให้อัตโนมัติ)

## ข้อควรระวัง
- ข้อมูลมีต้นทุน GP และยอดขายรายสาขา ลิงก์ GitHub Pages / Vercel เปิดได้สาธารณะ ควรตั้ง repo เป็น Private และเปิดการป้องกันด้วยรหัสผ่านใน Vercel
- อย่า commit ไฟล์ Excel ต้นฉบับ (กันไว้แล้วใน .gitignore)
